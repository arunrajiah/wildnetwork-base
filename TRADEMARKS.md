# Name and logo

The Wildlife Network Base software in this repository is open source under the Apache License 2.0 (see LICENSE), and you are welcome to run, study, change and share it under that licence.

The name "Wildlife Network" and the Wildlife Network logo (`assets/logo.svg`, also built into the dashboard) are not covered by the code licence; the Apache License 2.0 does not grant trademark rights either (section 6). They identify the project run by Arun Rajiah at wlnw.org, so that people know which map, data releases and methods they are relying on.

## You may, without asking

- Say that your software is based on, forked from, or compatible with Wildlife Network, for example "built on Wildlife Network" or "a fork of Wildlife Network".
- Refer to Wildlife Network by name when you write about it, cite its data releases, or link to it.
- Keep the name and logo in unmodified copies of the code, its documentation and SD card images built from it.

## Please ask first

- Running a public site, app or service, or selling or handing out devices, called Wildlife Network or Wildlife Network Base, or with a name or logo that could be confused with them.
- Using the logo in your own product, or in a way that suggests Wildlife Network endorses or runs your project.
- Using the name in a domain name, organisation name or product name.

If you run a fork as a public service or ship devices with a changed version, please give it its own name and logo (replace `assets/logo.svg` and the copy in `base/wnbase.py`), and make clear that it is independent. Its data, methods and results are its own.
